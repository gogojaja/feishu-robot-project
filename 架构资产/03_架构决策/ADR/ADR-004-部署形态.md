# ADR-004 部署形态：LaunchAgent 常驻

> 状态：已接受　类型：技术选型　日期：2026-08-12
> 架构阶段：环节 3（record_decisions）｜替代：旧 ADR-004（nohup 手动，已废弃）

## 背景

OpenClaw Gateway 需常驻运行并可自动恢复。候选：LaunchAgent 常驻 vs 手动进程。

## 决策

- **主方案**：macOS LaunchAgent 常驻（`~/Library/LaunchAgents/ai.openclaw.gateway.plist`），开机自启 + `openclaw gateway status/logs` 可查。
- **废弃**：手动 nohup 启动自研服务。

## 权衡

| 维度 | LaunchAgent（取） | nohup 手动（弃） |
|------|--------------------|------------------|
| 开机自启 | 支持 | 不支持 |
| 状态可查 | status 命令 | 需 ps |
| 崩溃恢复 | 自动重启 | 手动 |

## 理由

N-REQ-09 要求 Gateway 常驻与状态检查；LaunchAgent 为 macOS 原生机制，符合环境规范。

## 影响

- 正向：Gateway 稳定常驻（pid 4639 运行中）
- 负向：自研服务端口 5101-5103 需释放
- 关联：N-REQ-09/N-REQ-16；ARCH-RISK-109
