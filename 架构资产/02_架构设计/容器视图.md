# 容器视图（C4 Container）— OpenClaw 体系（v0.3）

## 容器划分

| 容器 | 类型 | 职责 | 技术 | 状态 |
|------|------|------|------|------|
| feishu channel | 渠道插件 | WebSocket 长连接接收/发送 | @openclaw/feishu | 运行中 |
| Gateway core | 进程 | 编排/路由/权限/会话 | OpenClaw 2026.7.1-2 | 运行中 |
| acpx | 运行时插件 | ACP adapter，spawn opencode | @openclaw/acpx | 已安装 |
| opencode-acp agent | Agent | 绑定 ACP 会话 | opencode 1.17.4 | persistent |
| opencode CLI | 执行器 | ACP server + 模型推理 | opencode/deepseek-v4-flash-free 等 | 按需 |
| 配置存储 | 文件 | 声明式配置 | ~/.openclaw/openclaw.json（0600） | 运行中 |

## C4 Container 图

```
┌─────────────────────────────┐
│   飞书/Lark 客户端（用户）   │
└──────────────┬──────────────┘
               │ WebSocket 长连接 / CardKit
               ▼
┌─────────────────────────────────────────────┐
│           OpenClaw Gateway（容器）          │
│  ┌─────────────┐   ┌──────────────────┐    │
│  │ feishu渠道  │   │   Gateway core   │    │
│  │ (plugin)    │──▶│  (编排/路由)     │    │
│  └─────────────┘   └────────┬─────────┘    │
│                             │ ACP          │
│  ┌──────────────────────────▼──────────┐   │
│  │        acpx（ACP adapter）          │   │
│  │  agent=opencode mode=persistent    │   │
│  └─────────────────────────────────────┘   │
└──────────────────────┬─────────────────────┘
                       │ stdin/stdout（ACP）
                       ▼
              ┌─────────────────┐
              │  opencode CLI   │
              │  (ACP server)   │
              │  模型推理+任务执行│
              └─────────────────┘
```

## 容器间通信

- 飞书↔Gateway：WebSocket（im.message.receive_v1）+ CardKit 卡片 API
- Gateway↔OpenCode：ACP（Agent Client Protocol，stdin/stdout）
- 运维↔Gateway：openclaw gateway status/logs/pairing
