# 架构设计文档 — 飞书+OpenClaw+OpenCode（v0.3）

> 角色：架构设计师（design_architecture）｜依据：SRS v0.3 + 架构策略分析报告 v0.3
> 版本：v0.3　日期：2026-08-12

## 1. 架构风格与总体策略

**风格**：网关编排式（Orchestrator Gateway）· 三层架构 · 配置驱动（声明式 bindings）

**三层**：
```
飞书/Lark（客户端）→ OpenClaw Gateway（中间层）→ OpenCode（本地AI编程CLI）
```

**理由**：
- 用户原始设想：OpenClaw 作为统一网关调度本地 OpenCode
- 官方 feishu 长连接免公网；ACP 协议承载 OpenCode 集成
- 配置驱动：bindings/agents.list/dmPolicy/requireMention 全部声明式

**分层**（OpenClaw 进程内）：
- 接入层：feishu 渠道（WebSocket 长连接）
- 编排层：Gateway（Agent 编排/Skills/多模型/MCP）
- 执行层：ACP adapter（acpx）→ OpenCode ACP server
