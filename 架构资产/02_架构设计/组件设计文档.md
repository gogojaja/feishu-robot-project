# 组件设计文档 — OpenClaw 体系（v0.3）

## 组件清单

| 组件 | 所属容器 | 职责 | 接口 | 依赖 | 生命周期 |
|------|----------|------|------|------|----------|
| FeishuWebSocket | feishu channel | 长连接接收/发送事件 | im.message.receive_v1 | 飞书开放平台 | Gateway 启动即连 |
| MentionFilter | feishu channel | requireMention 过滤 | 消息预处理 | — | 接收时 |
| DmPolicyGuard | feishu channel | allowlist 白名单 | 消息预处理 | 配置 | 接收时 |
| BindingRouter | Gateway core | bindings 路由到 agent | 路由表 | agents.list | 消息时 |
| PermissionGate | Gateway core | 权限确认卡片 | once/always/reject | CardKit | 权限请求时 |
| SessionStore | Gateway core | chat↔session 映射持久化 | 映射表 | 磁盘 | 全周期 |
| StreamCard | Gateway core | CardKit 流式卡片更新 | SSE | 飞书卡片API | 生成时 |
| AcpxAdapter | acpx | spawn opencode ACP server | ACP stdin/stdout | opencode CLI | persistent |
| OpenCodeServer | opencode | 模型推理/任务执行 | ACP server | 本地模型 | 按需拉取 |

## 组件依赖（无循环依赖）

```
FeishuWebSocket → MentionFilter → DmPolicyGuard → BindingRouter → AcpxAdapter → OpenCodeServer
        └───────────────┬───────────────────────────┘
                        ▼
                  PermissionGate / StreamCard
                  SessionStore（横向支撑）
```

## 关键组件详述

### FeishuWebSocket
- 职责：飞书长连接客户端，免公网 IP
- 触发：飞书平台事件推送（WebSocket 模式，需后台切换订阅方式）
- 输出：事件元数据（不落完整事件体，N-REQ-11 仅记元数据）

### BindingRouter
- 职责：按 bindings 配置将群聊 `oc_7e3442d95ddf0b3c226cb528a4db2ced` 消息路由到 opencode-acp agent
- 配置：`~/.openclaw/openclaw.json` bindings 段

### AcpxAdapter
- 职责：ACP 运行时插件，以 persistent 模式维护 opencode ACP 会话
- 配置：agent=opencode、backend=acpx、mode=persistent、cwd=项目根

### SessionStore
- 职责：chat↔session 映射持久化，重启后恢复会话（N-REQ-08）
- 说明：接受落盘（决策已反转），与自研内存态方案不同

## 通信与幂等

- 通信协议：ACP（OpenCode）、WebSocket（飞书）、CLI（运维）
- 幂等：requireMention 保证群聊仅 @ 触发；单通道停用自研服务避免重复回复（N-REQ-16）
