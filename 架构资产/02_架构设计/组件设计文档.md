```
C1 WebhookController ─► C5 EventProcessor ─► C6 SessionManager
                                        ├─► C7 DedupManager
                                        ├─► C8 OpenCodeRunner ─► C12 FeishuClient(无关)
                                        ├─► C9 OutputSanitizer

                                        ├─► C11 InputValidator
                                        └─► C12 FeishuClient（发送回复）

C3 PageController ─► C2

```

## 3. 组件接口契约

| 组件 | 关键接口 | 签名 | 说明 |
|------|----------|------|------|
| C1 | webhook() | POST → JSON | challenge 原样返回；非 receive_v1 跳过；去重后异步处理 |
| C2 | api_chat() | POST {message, session_id} → {response, session_id} | 空消息 400 |
| C5 | process(event) | dict → None | 校验→非文字提示→取会话→run→回写会话→发送 |
| C6 | get(open_id)/put(open_id,sid) | str→str / None | Lock 保护 |
| C8 | run(msg, sid) → (resp, new_sid) | str,str → tuple | timeout=180；解析 JSON Lines；超时/未装兜底 |
| C9 | strip(text) / truncate(text) | str→str | ANSI 正则清理；15000 截断保留代码块 |
| C10 | check(open_id) | str→bool | 固定窗口 10 条/分钟 |
| C12 | get_token() / send(open_id,text) | →bool | 过期刷新；失败重试 1 次+告警 |

## 4. 组件生命周期与通信

- **进程级**：全部组件随 Flask 进程启动常驻，无独立生命周期管理
- **会话对象**：内存 dict，随消息创建/更新，进程重启丢失（接受，记录日志）
- **线程模型**：webhook 同步响应后，C5 在 daemon 线程执行；C6/C7 的集合操作受 `_dedup_lock` 保护
- **子进程**：C8 每次 run 派生一次性 opencode 子进程，180s 超时 kill

## 5. 反循环依赖检查

- 依赖图无环 ✅；C8 不反向依赖 C12；C5 为唯一编排中枢（单点控制）
