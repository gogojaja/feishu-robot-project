# 接口设计文档 — OpenClaw 体系（v0.3）

> 依据：SRS v0.3 03_外部接口需求.csv（IF-001~008）

## 接口契约

| 接口 | 方向 | 协议 | 触发 | 输入 | 输出 | 关联需求 |
|------|------|------|------|------|------|----------|
| IF-001 飞书长连接事件 | 飞书→OpenClaw | WebSocket | 事件推送 | im.message.receive_v1 | 事件处理 | N-REQ-01/04 |
| IF-002 ACP 会话控制 | OpenClaw→OpenCode | ACP | bindings 路由 | 消息帧 | 回复回传 | N-REQ-02 |
| IF-003 OpenCode ACP server | OpenClaw→OpenCode | stdin/stdout | 首次 spawn | ACP 协议帧 | 会话就绪 | N-REQ-03 |
| IF-004 飞书 CardKit 流式 | OpenClaw→飞书 | HTTPS 卡片API | SSE 事件 | 卡片 JSON | 实时更新 | N-REQ-05 |
| IF-005 权限确认回传 | OpenClaw→OpenCode | ACP | permission/question | once/always/reject | 任务继续 | N-REQ-06 |
| IF-006 Gateway 状态查询 | 运维→OpenClaw | CLI | 手工/脚本 | status/logs 参数 | 状态/日志 | N-REQ-09/11 |
| IF-007 媒体收发 | 飞书↔OpenClaw | WebSocket/上传API | 媒体消息 | 文件ID/内容 | 媒体回传 | N-REQ-14 |
| IF-008 模型切换指令 | 用户→OpenClaw | 群聊文本 | /model 指令 | 模型名 | 切换生效 | N-REQ-12 |

## 错误处理

| 场景 | 处理 |
|------|------|
| ACP 连接中断 | acpx 重连/spawn 重试（N-REQ-13） |
| 飞书断连 | OpenClaw WebSocket 自动重连（N-REQ-13） |
| 权限拒绝 | 回传 reject，任务终止（N-REQ-06） |
| 非白名单私聊 | DmPolicyGuard 拒答（N-REQ-07） |
| 非 @ 群聊消息 | MentionFilter 忽略（N-REQ-04） |

## 认证与授权

- 凭证：飞书 app_id/app_secret 存于 ~/.openclaw/openclaw.json（0600，不入仓库，N-REQ-10）
- 授权：dmPolicy=allowlist（私聊）+ permission 确认卡片（高危操作）
- 范围：bindings 限定单群，避免误路由

## 限流与熔断

- 限流：依赖 OpenClaw Gateway 内建策略；单用户场景低风险
- 熔断：ACP adapter 异常时重试，连续失败告警（openclaw logs）
