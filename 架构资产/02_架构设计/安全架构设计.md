# 安全架构设计 — OpenClaw 体系（v0.3）

> 依据：SRS v0.3（N-REQ-06/07/10/15）+ 台账禁止项

## 安全边界

```
信任区：OpenClaw Gateway 进程（含配置/会话）
半信任区：OpenCode（本地 CLI，项目工作目录）
外部：飞书平台（凭证认证）、用户（白名单/权限确认）
已废弃：自研桥接（不再暴露端口）
```

## 安全控制

| 控制项 | 措施 | 关联需求 |
|--------|------|----------|
| 凭证保护 | 配置 0600、不入仓库、不写日志 | N-REQ-10 |
| 私聊白名单 | dmPolicy=allowlist，非白名单拒答 | N-REQ-07 |
| 群聊触发控制 | requireMention=true，仅 @ 触发 | N-REQ-04 |
| 权限确认 | permission/question 卡片（once/always/reject） | N-REQ-06 |
| 会话隔离 | 群按 groupSessionScope、私聊按用户隔离 | N-REQ-08 |
| 环境约束 | 仅 test（.env_type=test）；禁 /Users/gogo；禁 sudo | N-REQ-15 |
| 端口约束 | 仅 5101/5102/5103（自研停用）+18789（OpenClaw） | N-REQ-15 |
| 事件日志 | 仅记元数据，不落完整事件体/凭证 | N-REQ-11 |
| 单通道 | 自研服务停用，避免双通道 | N-REQ-16 |

## 威胁建模

| 威胁 | 缓解 |
|------|------|
| 凭证泄露 | 0600+不入仓库+日志脱敏 |
| 越权回复 | 白名单+requireMention+单群绑定 |
| 会话串访 | 群/用户隔离 |
| 命令注入/危险操作 | 权限确认卡片 |
| 环境越界 | 禁 sudo+禁 /Users/gogo+仅 test |
| 双通道重复 | 自研停用 |

## 合规

- 满足台账禁止项：不开发新功能、不部署生产、不改 AGENTS.md 核心规则、不清理既有文件
- 数据最小化：元数据留痕，完整事件体不落盘
