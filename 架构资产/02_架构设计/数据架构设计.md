# 数据架构设计 — OpenClaw 体系（v0.3）

> 依据：SRS v0.3（N-REQ-08 会话持久化、N-REQ-11 日志留痕、N-REQ-10 凭证保护）

## 数据实体

| 实体 | 内容 | 存储位置 | 持久化 | 权限 | 关联需求 |
|------|------|----------|--------|------|----------|
| chat↔session 映射 | 群/用户 ↔ OpenCode 会话ID | OpenClaw session 存储 | 是（落盘） | 受保护 | N-REQ-08 |
| 会话历史 | 对话上下文 | OpenCode session | 是 | 受保护 | N-REQ-08 |
| 消息内容 | 群聊/私聊消息 | 落盘（决策已反转，接受） | 是 | 受保护 | 决策2 |
| 事件元数据 | 时间/chat_id/事件类型 | openclaw logs | 是 | 受保护 | N-REQ-11 |
| 配置凭证 | app_id/app_secret/token | ~/.openclaw/openclaw.json | 是 | 0600 | N-REQ-10 |
| 白名单 | allowlist 用户 | 配置 | 是 | 0600 | N-REQ-07 |

## 数据流

```
用户消息 → feishu WebSocket → Gateway（元数据留痕，完整事件体不落盘）
    → bindings 路由 → ACP → OpenCode 会话（chat↔session 映射持久化）
    → 回复 → CardKit 流式卡片 → 飞书群
```

## 数据策略

| 项 | 策略 |
|----|------|
| 会话持久化 | 接受落盘（决策反转），重启后映射恢复，设备接力不丢失 |
| 消息落盘 | 接受（决策2），与自研「仅内存态」方案不同 |
| 日志 | 仅记元数据（N-REQ-11 关键事件），不记完整事件体/凭证 |
| 凭证 | 0600 权限，不入仓库，不写日志 |
| 数据隔离 | 群聊按群隔离会话（groupSessionScope），私聊按用户隔离 |

## 隐私与合规

- 单用户+AI助理模式，数据范围限定 test 环境
- 原始事件不落盘完整内容（与 SRS REQ-SEC-001 修订一致）
- 废弃自研服务不再产生数据通道（N-REQ-16）
