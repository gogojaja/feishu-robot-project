## 参与者（外部实体）

| 实体 | 类型 | 交互 | 约束 |
|------|------|------|------|
| 飞书用户 | 人 | 通过飞书 APP 发送消息/接收回复 | 以 open_id 标识；单用户模式 |
| 飞书开放平台 | 外部系统 | 推送事件；提供 Token/发送 API | HTTPS；challenge 1 秒响应 |
| OpenCode CLI | 外部程序 | 被 subprocess 调用执行编程任务 | 本机安装；--session 复用会话 |
| Web 浏览器 | 人 | 通过 /chat 页面聊天 | 调用 /api/chat |

## 边界

- 系统**不**直接访问飞书数据库/存储；全部经开放平台 API
- 系统**不**向磁盘写入任何消息内容（REQ-DATA-REQ-001）
- 外部公网仅依赖 ngrok 隧道（本地验证用）
