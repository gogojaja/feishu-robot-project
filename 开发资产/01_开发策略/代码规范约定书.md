# 代码规范约定书 — 飞书机器人项目

> 开发策略环节 1　版本：v0.1　2026-08-05

## 1. 文件头注释（AGENTS.md §15 强制）

```python
"""
模块名称：<文件名或模块名>
功能描述：<一句话说明模块做什么>
对外接口：
    - function(param): 功能说明
依赖：
    - 标准库：os, sys, json, logging, threading, subprocess, pathlib, time
    - 第三方：requests, flask, pyyaml
    - 项目内：（按实际依赖填写）
版本：v1.0
更新记录：
    - YYYY-MM-DD: 说明
"""
```

## 2. 命名规范
- 类名 PascalCase；函数/变量 snake_case；常量 UPPER_SNAKE_CASE
- 模块拆分（T1 触发）：opencode_runner / output_sanitizer / rate_limiter / input_validator / feishu_client

## 3. 编码铁律
- 文件超 500 行自动模块化拆分
- 内置 DEBUG 级日志；输出前语法自检
- 外部输入必须验证（入站 4KB + 类型白名单）
- 禁止硬编码配置（外部化 config/feishu.yaml + 环境变量）
- 禁止循环依赖；禁止 sudo；凭证不写日志

## 4. 提交规范
- Trunk-Based：小步高频提交；每次可编译完整
- 提交信息：`feat(dev): <模块> <功能>` 风格

## 5. 审查依据
- 本规范为代码走查（环节 5）与 PR 评审的检查依据
