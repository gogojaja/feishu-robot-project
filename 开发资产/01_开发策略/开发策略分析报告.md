## 2. 分支策略

- **方案**：Trunk-Based Development（单主分支 main，短生命周期小提交）
- **理由**：单开发者单机 test 环境；架构基线要求小步提交；无并行协作需求
- **规则**：每次提交为可编译完整代码；功能缺口逐条完成；提交前过本地检查

## 3. 编码规范（依据 AGENTS.md §15/16 + 架构开发指南）

- Python 文件顶部固定格式注释（模块名称/功能描述/对外接口/依赖/版本/更新记录）
- 内置 DEBUG 级日志；输出前语法自检；禁止残缺半成品
- 禁止硬编码配置（外部化 config/feishu.yaml + 环境变量）
- 外部输入必须验证；禁止循环依赖；禁止 sudo
