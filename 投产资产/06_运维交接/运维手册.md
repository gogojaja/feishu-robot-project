## 3. 故障排除

| 症状 | 排查步骤 |
|------|---------|
| 流式卡片 400（`streaming start failed ... HTTP 400`） | **已闭环（2026-08-19）**：根因=cardkit:card:write 仅授权 user 身份非 tenant；处置=平台权限管理加入 tenant 数组+发布新版本+重启 Gateway。验证脚本 `scripts/diag_cardkit_400.py`（详 `排查交接_流式卡片400_20260819.md`） |
| feishu channel 非 running | `openclaw channels status`；`openclaw logs`；检查 `~/.openclaw/openclaw.json` appId/appSecret；重启 `openclaw-gate-check.sh` |
| Gateway 未监听 18789 | `launchctl list | grep ai.openclaw.gateway`；`launchctl kickstart -k gui/$(id -u)/ai.openclaw.gateway` |
| 收到消息但无回复 | 观察日志是否 `dispatch complete (replies=N)`；N=0 多为 opencode ACP 侧未产出文本 |
| 入站被拒 | 检查白名单（DM open_id / 群 oc_xxx / requireMention）与 `openclaw pairing list feishu` |
| 端口占用 5102/5103 | 出现即废弃桥复活 → `lsof -ti:5102,5103` 找进程 kill，并检查是否有脚本重新拉起 |
