> 依据：role-deployment handover.md §2.4 · 版本：v1.0　日期：2026-08-06

## 1. 服务概览

| 项 | 值 |
|----|-----|
| 服务 | 飞书→OpenCode 桥接（单文件 Flask） |
| 端口 | 5101（预留回调）/ 5102（opencode serve）/ 5103（Flask） |
| 进程 | feishu_integration.py（Flask）+ opencode serve |
| 日志 | feishu_bot.log / opencode_server.log / opencode_server.pid / feishu_bot.pid |
| 数据 | var/opencode.db（会话库，非核心可重建） |

## 2. 日常操作

### 2.1 启动
```bash
bash scripts/start-feishu.sh
```

### 2.2 停止
```bash
bash scripts/stop-feishu.sh
```

### 2.3 健康检查
```bash
curl http://127.0.0.1:5103/health   # 期望 {"status":"ok"}
curl -s -o /dev/null -w "%{http_code}\n" http://127.0.0.1:5102/  # 期望 200
```

### 2.4 环境核验
```bash
python3 scripts/check_env.py   # .env_type 须为 test
```

### 2.5 冒烟测试
```bash
python3 scripts/test_feishu.py
```

## 3. 故障排除

| 症状 | 排查步骤 |
|------|---------|
| /health 无响应 | 检查 PID：`cat feishu_bot.pid`；`ps -p $(cat feishu_bot.pid)`；日志 `tail -50 feishu_bot.log` |
| opencode 报 Session not found | 确认 serve 监听：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:5102/`；重启 `bash scripts/start-feishu.sh` |
| 发送失败重试/告警 | 查看 feishu_bot.log 中「发送失败」：多为无效 open_id（test 环境预期）；真实 open_id 验证待投产 |
| 端口被占用 | `lsof -ti:5103`（仅限 510x）；停旧进程后重启 |
| 入站消息被拒 | 日志「入站消息超长（5000 字符）」：飞书端限制消息长度 |
