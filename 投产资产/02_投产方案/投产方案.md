# 投产方案 — M6 投产部署（test 环境）

> 依据：role-deployment planning.md · 投产策略分析（01_投产策略）· 版本：v1.0　日期：2026-08-06

## 1. 投产目标

- 业务目标：飞书→OpenCode 桥接服务在 test 环境正式投产，实现消息自动应答与文件处理
- 技术目标：单文件 Flask 服务 + opencode serve 常驻，全链路（回调→解析→推理→发送重试）稳定
- 预期收益：移动端/桌面端经飞书调用本机 OpenCode，交互与终端一致

## 2. 投产范围

| 变更项 | 内容 | 说明 |
|--------|------|------|
| src/feishu_integration.py | 桥接核心（403 行） | 含 C8-C12 全部能力 |
| scripts/start-feishu.sh | 启动脚本（55 行） | serve 生命周期 + 健康等待 |
| scripts/stop-feishu.sh | 停止脚本（30 行） | 清理进程 |
| scripts/test_feishu.py | 测试脚本 | 冒烟验证用 |
| config/feishu.yaml | 配置（app_id/secret/port） | 仅 test 凭证 |
| requirements.txt | 依赖锁定 | requests/flask/pyyaml |

排除项：不部署生产环境（范围基准）、不新增功能、不改动 AGENTS.md 核心规则。

## 5. 部署步骤

1. 前置检查：`python3 scripts/check_env.py`（.env_type=test）→ 端口 5101 可用/5102-5103 服务状态
2. 构建部署包：git 当前 HEAD（d274026）+ 源码/脚本/config 清单核对
3. 备份：当前运行文件 → `备份/M6_20260806/`
4. 停止旧服务：`bash scripts/stop-feishu.sh`
5. 启动：`bash scripts/start-feishu.sh`
6. 冒烟：`curl http://127.0.0.1:5103/health` + `python3 scripts/test_feishu.py`
7. 真实链路：POST /feishu/events 回调解析验证
8. 稳定期观察：2-4h 日志无异常
