## 2. 入站接口契约

### 2.1 POST /feishu/events（飞书事件回调）
**请求**：`application/json`
```json
{ "type": "event_callback", "event": { "type": "im.message.receive_v1",
  "sender": {"sender_id": {"open_id": "ou_xxx"}},
  "message": {"message_id": "om_xxx", "message_type": "text", "content": "{\"text\":\"你好\"}"} } }
```
**URL 验证请求**：`{ "type":"url_verification", "challenge":"xxx", "token":"xxx" }`
**响应**：
- url_verification → `{"challenge":"xxx"}`（1 秒内原样返回，REQ-FUNC-REQ-001）
- event_callback(receive_v1) → `{"status":"ok"}`（异步处理）
- 重复 message_id → `{"status":"duplicate"}`
- 其他事件 → `{"status":"skip"}`
**约束**：入站 >4096 字符拒绝（REQ-FUNC-REQ-012，C11 待开发）

### 2.2 POST /api/chat（HTTP 聊天）
**请求**：`{ "message": "str", "session_id": "str(可选)" }`
**响应 200**：`{ "response": "str", "session_id": "str" }`
**响应 400**：`{ "error": "empty message" }`
**约束**：无 session_id 时自动生成（uuid4）；映射到 opencode session。

### 2.3 GET /chat / GET /health
- /chat → HTML 页面（内嵌 JS 调 /api/chat）
- /health → `{"status":"ok"}`

## 3. 出站接口契约

### 3.1 POST 获取 tenant_access_token
**请求体**：`{"app_id":"...","app_secret":"..."}`（30s 超时）
**响应**：`{"code":0,"tenant_access_token":"t-xxx","expire":7200}`
**策略**：缓存内存态，`time.time()>expire_time` 时刷新；连续失败≥3 次告警（REQ-FUNC-REQ-017 待补）。

### 3.2 POST 发送消息
**URL**：`/open-apis/im/v1/messages?receive_id_type=open_id`
**请求体**：`{"receive_id":"ou_xxx","msg_type":"text","content":"{\"text\":\"...\"}"}`
**响应**：`{"code":0,...}`；失败记录日志并重试 1 次（REQ-FUNC-REQ-018 待补）。

### 3.3 opencode CLI 子进程
**命令**：`opencode run <message> --format json --dangerously-skip-permissions [--session <sid>]`
**超时**：180s（REQ-FUNC-REQ-010）
**输出**：JSON Lines stream，取 `type=="text"` 的 `part.text` 拼接；`sessionID` 字段更新会话
**环境**：移除 OPENCODE_SERVER_PASSWORD/USERNAME（REQ-FUNC-REQ-011）

## 4. 接口通用规范

- **版本管理**：飞书事件 v1.0/v2.0 兼容（仅订阅 receive_v1）；API 契约以本文档为基线固化
- **错误码**：HTTP 400=参数错误；业务错误以 JSON `{"error":...}` 表达；飞书侧错误以平台 code 为准
- **认证授权**：入站事件靠验证 token/challenge；无鉴权 API（test 环境，最小暴露面）
- **限流熔断**：open_id 级固定窗口限流（C10，Should）；无熔断（单用户场景）
- **安全**：凭证不出现在任何日志/响应体；消息内容不落盘

## 5. 接口变更影响（基线后走 change_analysis）

- 变更 /feishu/events 契约 → 影响飞书后台配置与 C1/C5/C6/C7/C10/C11
- 变更 opencode 调用 → 影响 C8 与会话映射
- 变更后更新追溯矩阵（台账 08）
