# 容器视图（C4 Container）— 飞书机器人项目

> 依据：架构设计文档 §3.2　角色：架构设计师　版本：v0.1　2026-08-05

## 容器清单

| 容器 | 技术 | 职责 | 与系统关系 |
|------|------|------|-----------|
| 飞书机器人应用容器 | Python 3 + Flask（threaded=True） | 事件接收、会话管理、opencode 调用、输出处理、限流、健康检查 | 本系统唯一业务容器 |
| 飞书开放平台 | 云端 SaaS | 事件推送、Token 签发、消息中继 | 外部依赖（HTTPS） |
| OpenCode CLI | 本机二进制 v1.17.4 | 执行编程任务、返回 JSON stream | 外部依赖（子进程） |
| Web 浏览器 | 用户客户端 | 渲染 /chat 页面并调 /api/chat | 外部客户端 |

## 容器间通信协议

| 源容器 | 目标容器 | 协议 | 数据格式 |
|--------|----------|------|----------|
| 飞书开放平台 | 应用容器 | HTTPS POST | JSON（事件回调） |
| 应用容器 | 飞书开放平台 | HTTPS POST | JSON（Token/发送） |
| 应用容器 | OpenCode CLI | subprocess（stdin/stdout） | JSON Lines stream |
| 浏览器 | 应用容器 | HTTP GET/POST | JSON（/api/chat）/ HTML（/chat） |
