# ATAM 权衡分析报告 — 飞书机器人项目

> 依据：review.md 环节 1（record_decisions）· 版本：v0.1　日期：2026-08-05

## 1. 质量属性目标（含优先级）

| 质量属性 | 目标 | 优先级 | 关键场景 |
|----------|------|--------|----------|
| 可用性 | ≥99%（单机存活口径） | 高 | /health 探针，进程存活 |
| 性能 | P95≤15s；超时 180s | 高 | 文本应答链路 |
| 可靠性 | 并发安全 + 幂等去重 | 高 | 多消息并发、重复推送 |
| 安全性 | 凭证零泄露 + 会话隔离 | 高 | STRIDE 威胁场景 |
| 隐私 | 消息不落盘 | 高 | 磁盘扫描 |
| 可维护性 | 关键事件日志留痕 | 中 | 审计链 |

## 2. 关键权衡（Tradeoffs）

### T1 可维护性 ↔ 部署成本（ADR-004）
- **取舍**：牺牲模块化（单体 334 行）换取零依赖、单进程极简部署
- **决策**：单体 + 逻辑组件划分 + 预留拆分扩展点；七原则「模块化/内聚」以逻辑组件粒度达成

### T2 可用性 ↔ 会话持久化（ADR-003）
- **取舍**：牺牲重启后上下文恢复换取隐私合规（不落盘）+ 零采购
- **决策**：内存态 + 记录 session_id 日志兜底；单机存活口径接受（ARCH-RISK-010）

### T3 接入成本 ↔ 长期稳定性（ADR-001）
- **取舍**：Webhook 接入快但依赖 ngrok 稳定性；长连接稳定但需 SDK 迁移
- **决策**：Webhook 为主 + 长连接迁移预案，两全兼顾

### T4 安全纵深 ↔ 使用便捷（ADR-005）
- **取舍**：限流/长度校验增加实现复杂度，换取防滥用与防注入
- **决策**：安全优先级最高（AGENTS §18），C10/C11 为开发阶段硬性补齐项

## 3. 各 ADR 质量属性评估

| ADR | 正向贡献 | 潜在风险 | 缓解 |
|-----|----------|----------|------|
| ADR-001 | 可用性/部署便捷 | ngrok 中断 | 长连接预案 |
| ADR-002 | 性能/会话连续 | 子进程启动开销 | 单用户可接受 |
| ADR-003 | 隐私/零成本 | 重启丢上下文 | 日志兜底 |
| ADR-004 | 部署/运维极简 | GIL 并发上限 | 单用户假设 |
| ADR-005 | 安全/隔离 | 凭证管理复杂度 | 最小权限+YAML |

## 4. 结论

- **无高优先级风险未闭环**；五个 ADR 权衡均与单用户+test 环境约束自洽
- 待开发安全缺口（限流/入站校验/重试告警）作为 M4 输入，不影响架构基线
- 风险处置引用架构风险登记册 ARCH-RISK-001~010
