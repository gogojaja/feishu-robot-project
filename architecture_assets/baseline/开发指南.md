# 开发指南

## 1. 编码规范

### 1.1 Python 代码规范

- **PEP 8**：遵循 Python 官方代码风格指南
- **命名规范**：
  - 变量/函数：小写字母 + 下划线（snake_case）
  - 类名：大驼峰（PascalCase）
  - 常量：大写字母 + 下划线（UPPER_CASE）
- **注释规范**：
  - 模块顶部：固定格式注释（参见《AGENTS.md》）
  - 函数/方法：Docstring 注释

### 1.2 命名规范

| 类型 | 命名规范 | 示例 |
|------|----------|------|
| **变量** | snake_case | `open_id`, `message_id` |
| **函数** | snake_case | `_process()`, `get_token()` |
| **类** | PascalCase | `FeishuBot` |
| **常量** | UPPER_CASE | `BASE_DIR`, `SESSION_FILE` |

### 1.3 注释规范

- **模块注释**：固定格式注释（参见《AGENTS.md》）
- **函数注释**：Docstring 格式
- **行注释**：解释复杂逻辑

## 4. 开发环境搭建

### 4.1 环境要求

| 组件 | 版本 | 说明 |
|------|------|------|
| **Python** | 3.11+ | Python 3.11 LTS |
| **pip** | 21.0+ | Python 包管理工具 |
| **Docker** | 20.10+ | 可选，用于容器化部署 |

### 4.2 安装步骤

#### 步骤 1：安装 Python 3.11

```bash
# macOS
brew install python@3.11

# Linux
sudo apt-get install python3.11

# Windows
# 下载安装包：https://www.python.org/downloads/
```

#### 步骤 2：安装依赖

```bash
pip install -r requirements.txt
```

#### 步骤 3：配置飞书应用

编辑 `config/feishu.yaml`：

```yaml
app_id: "cli_xxx"
app_secret: "your_app_secret_here"
verification_token: ""

host: "0.0.0.0"
port: 5103
```

#### 步骤 4：启动服务

```bash
bash scripts/start-feishu.sh
```

#### 步骤 5：验证服务

```bash
curl http://127.0.0.1:5103/health
python3 scripts/test_feishu.py
```

## 8. 部署

### 8.1 Docker 部署

#### 构建镜像

```bash
docker build -t feishu-bot:latest .
```

#### 运行容器

```bash
docker run -d \
  --name feishu-bot \
  -p 5103:5103 \
  -v $(pwd)/var:/app/var \
  -e FEISHU_APP_ID=${FEISHU_APP_ID} \
  -e FEISHU_APP_SECRET=${FEISHU_APP_SECRET} \
  -e FEISHU_VERIFICATION_TOKEN=${FEISHU_VERIFICATION_TOKEN} \
  feishu-bot:latest
```

### 8.2 Docker Compose 部署

```bash
docker-compose up -d
```

## 10. 常见问题

### 10.1 环境验证失败

```bash
python3 scripts/check_env.py
```

### 10.2 端口被占用

释放 5103 端口：

```bash
lsof -ti:5103 | xargs kill -9
```

### 10.3 模块导入失败

确保在项目根目录运行：

```bash
cd /path/to/feishu-robot-project
python3 scripts/test_feishu.py
```

### 10.4 功能异常

检查日志文件：`feishu_bot.log`
